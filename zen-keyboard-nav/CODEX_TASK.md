# Задача Codex: развитие Zen Keyboard Navigator

Ты работаешь в директории Firefox/Zen WebExtension. В ней уже есть `manifest.json`, `content.js`, `README.md`. Сначала изучи проект. Цель — сделать качественную навигацию по сайтам исключительно клавиатурой, но **только после явного включения режима**.

## Функциональность, которую нельзя ломать

- `F8` включает/выключает режим в активной веб-странице. По умолчанию он выключен. При выключении исчезают все рамки и метки, а клавиши снова управляются сайтом.
- `F` рисует буквенные подсказки на видимых кликабельных элементах; набор комбинации активирует цель. `Shift+F` пытается открыть ссылку в отдельной вкладке.
- Стрелки перемещают яркую рамку по интерактивным элементам, `Enter` активирует выбранный, `Shift+Enter` — в новой вкладке.
- На YouTube навигация стрелками должна отдавать приоритет карточкам видео: домашняя лента, поиск, рекомендации и Shorts; корректно работать при динамическом обновлении страницы.
- При вводе в `input`, `textarea`, `contenteditable` навигационные горячие клавиши не должны перехватываться; исключение — `F8`.
- Работать с русской и английской раскладкой (использовать `KeyboardEvent.code` для латинских команд).
- Никакого доступа к файлам пользователя, сбора истории, аналитики, телеметрии и стороннего JS.

## Следующие этапы

1. **Проверить архитектуру** и исправить баги прототипа: `hidden` у элементов со стилями в Shadow DOM, пропадающая рамка при прокрутке, избыточное число меток, неправильная сортировка элементов YouTube, навигация по сетке.
2. Вынести CSS в отдельный файл/модуль. Разделить `content.js` на понятные части, не вводя ненужную сборку на MVP.
3. Поддержать навигацию без перебора `Tab`: перемещение по сетке видео ближайшим соседом в направлении стрелки с сохранением примерной колонки при вертикальном движении.
4. Поддержать бесконечную ленту YouTube (MutationObserver с debounce, не наблюдать весь DOM без необходимости), переходы внутри SPA и изменение раскладки.
5. Улучшить алгоритм меток: избегать дублей ссылки на превью/название одного видео, искать элементы с aria-label и реальными click listeners там, где это возможно без вмешательства в JS страницы, стабильно позиционировать метки при прокрутке.
6. Добавить опциональный режим **YouTube-only grid** (отдельный от общего выбора ссылок) и настройки горячей клавиши активации.
7. Добавить автоматические тесты для генератора меток, пространственной навигации, фильтрации невидимых элементов; тестовые HTML-страницы и ручной чек-лист для Zen.
8. Обновить README с реальными инструкциями установки, перезагрузки и сборки XPI. Не утверждать, что постоянная установка без подписи работает в обычном Firefox/Zen.

## Критерии приёмки

- Открыть поиск Google: F8, F, набрать код, перейти по ссылке; F8 отключает захват нажатий.
- Открыть главную страницу YouTube: F8, стрелки перемещают видимую рамку между видео, Enter открывает выделенный ролик.
- Перейти на страницу ролика и далее в рекомендации: подсветка продолжает работать без перезагрузки.
- Начать ввод в поиск YouTube и проверить, что `f`, буквы, стрелки и Enter работают внутри поля обычным образом (кроме F8).
- Ввести текст в русском и английском IME, не ломая ввод.
- На странице с >100 интерактивных элементов метки не перекрывают критически UI и сохраняют уникальность.
- Нет ошибок в консоли и нет ненужной нагрузки на CPU при прокрутке.

## Требования к ответу

Сначала кратко опиши найденные проблемы, затем внеси правки в файлы, выполни доступные проверки (в том числе синтаксис JS/JSON), кратко объясни как протестировать в Zen и перечисли оставшиеся ограничения. Не выдавай предположения за результаты реального браузерного теста.
