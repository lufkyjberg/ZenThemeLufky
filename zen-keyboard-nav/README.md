# Zen Keyboard Navigator (прототип)

Небольшое расширение для Zen Browser / Firefox. **По умолчанию выключено**, работает только при явной активации на странице.

## Возможности

| Клавиша | Действие |
|---|---|
| `F8` | Включить/выключить клавиатурный режим на текущей странице |
| `↑ ↓ ← →` | Перемещать рамку между ссылками, а на YouTube — преимущественно видео |
| `Enter` | Открыть выделенный элемент |
| `Shift+Enter` | Открыть выделенную ссылку в новой вкладке |
| `F` | Показать буквенные метки на ссылках и кнопках, ввести буквы для выбора |
| `Shift+F` | Метки, открывающие ссылку в новой вкладке |
| `Esc` | Закрыть метки; если меток нет — выйти из клавиатурного режима |

Символы для меток привязаны к физическим клавишам, поэтому русская раскладка не мешает вводу кода.

## Установка в Zen Browser

1. Распаковать папку `zen-keyboard-nav` на компьютер.
2. В адресной строке открыть `about:debugging#/runtime/this-firefox` (или `about:debugging` → **This Firefox / Этот Firefox**).
3. Нажать **Load Temporary Add-on / Загрузить временное дополнение**.
4. Указать файл `manifest.json` из распакованной папки.
5. Открыть `https://www.youtube.com` или результаты поиска Google, обновить страницу, нажать `F8`.
6. В правом верхнем углу появится индикатор KEY NAV. Клавиши `F` и стрелки заработают в режиме навигации.

После правок `content.js`: `about:debugging` → **Reload / Перезагрузить** у дополнения, затем **обновить саму вкладку**.

**Важно:** временные расширения исчезают после перезапуска браузера. Для постоянной установки потребуется упаковать и подписать Firefox WebExtension (например, через AMO). Не меняйте настройки подписи Zen ради этого.

## Ограничения прототипа

- Не работает на внутренних страницах `about:`, на странице дополнений Mozilla и в ряде PDF/встроенных iframe.
- Сложные веб-приложения с Shadow DOM / Canvas / виртуализированными списками могут не показывать некоторые элементы.
- На YouTube подбор карточек — эвристика: сайт может изменить разметку.
- Метки перестраиваются при новом вызове `F`; если страница радикально поменялась, закройте и снова откройте метки.
- Видеоплеер YouTube может использовать стрелки сам. Для обычных хоткеев плеера выключайте KEY NAV через `F8`.
- Не тестировалось в запущенном Zen Browser; исходники проверяются статически.

## Безопасность

Нет фонового скрипта, сетевых запросов, сторонних зависимостей и передачи данных. Доступ к HTTP(S)-страницам нужен для наложения подсветки. Исходник: `content.js`.
